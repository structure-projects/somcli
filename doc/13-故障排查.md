# 故障排查

> 覆盖验收场景：SC-F01、SC-F02、SC-F04、SC-F05、SC-F06、SC-F07、SC-F08、SC-D03、SC-X02、SC-X06。

定位问题的通用顺序：先 `validate`，再 `--debug`，最后缩到单个资源。

```bash
somcli validate -f config.yaml
somcli install --debug -f config.yaml -n <资源名>
```

`validate` 只做静态检查（结构、引用、模板渲染），不连节点、不查缓存；
`-n/--name` 只装配置里被点名的那一个资源，方便把问题范围缩到最小。

下面按报错信息归类，引号里的是 somcli 实际会打印的字样。

## 配置校验

### `hosts 项 "x" 不在已声明节点中`

资源的 `hosts` 里写了一个名字，但 `nodes:` 段没有任何节点的 `host` 或 `ip` 等于它。
somcli 只认 `nodes[].host` / `nodes[].ip` 字面命中；不做 DNS 解析、不猜主机名缩写。
把目标节点加进 `nodes:`，或确认拼写。只有 `localhost` / `127.0.0.1` / `::1`
可以不经声明直接用。

### `hosts 项 "x" 无法解析：配置中没有声明 nodes`

整份配置没有 `nodes:` 段，却给资源写了远程 `hosts`。先声明节点。

### `安装清单里没有资源 "x"，可用：...`

`k8sConfig.resources` 或 `cni` 引用了内置安装清单（`configs/k8s/*.yaml`）里不存在的名字。
报错会把可用名全列出来，照单改成存在的资源名。资源名清单见
[`06-场景-Kubernetes.md`](06-场景-Kubernetes.md)。

### `k8sConfig.version 不要带 v 前缀` / `格式不对`

版本写成三段、不带 `v`：`1.30.0`，不是 `v1.30.0` 或 `1.30`。URL 模板里已经有一个 `v`，
带前缀会拼成 `vv1.30.0` 导致下载 404。

### `k8s 1.24.x 不能配 containerRuntime: docker`

dockershim 在 1.24 从 kubelet 移除。改用 `containerd`，或把 k8s 降到 1.23。

### `配置了 N 个 master 却没有 controlPlaneEndpoint`

多 master 必须给一个不随单机存亡的 apiserver 入口（VIP 或负载均衡），形如
`10.0.0.10:6443`。

## 连接与节点

### SSH 连不上 / `dial tcp ...:22: connect: connection refused`

检查 `nodes[].ip`、`user`、`sshKey`；确认目标机 sshd 在跑、22 端口可达、
密钥对应正确的用户。somcli 不替节点开 sshd。

### `docker is not installed` / `docker-compose is not installed`

装 Harbor、Swarm、或用 docker 运行时装 k8s 前，节点上必须先有 docker
（Harbor 还需要 `docker-compose`）。先用 `somcli docker install` 或自行装好。

### k8s 节点一直 NotReady

CNI 没装成功。somcli 在 kubeadm init 之后、worker 加入之前部署 CNI（flannel/calico）；
看这一步的输出。`kubectl get nodes` 在 CNI pod 起来之前不会 Ready。

## 下载与离线

### `离线模式下文件不存在: ... (请先在联网环境执行 somcli download 准备离线包)`

`--offline` 下缓存里缺这个文件。回联网机跑 `somcli download -f config.yaml`，
把整个 workdir 拷过来再装。

### `下载失败，超过最大尝试次数 5`

URL 不通、架构填错、或被墙。检查 URL 与 `{{.Arch}}` 渲染结果；国内环境加
`--github-proxy https://gh-proxy.com/`，或用 `source: aliyun` 换源（见
[`03-环境初始化.md`](03-环境初始化.md)）。4xx 不重试——地址写错会直接失败。

## 镜像与仓库

### `invalid scope: x, must be one of: harbor, k8s, all`

`-s/--scope` 只能是这三个值；用 `-f` 指定自己的清单时 scope 仍要合法（但会被忽略）。

### `images pull/export` 用了 `-i`，或 `push` 用了 `-f`

四个子命令的清单标志不一样：`pull`/`export` 用 `-f/--file`，`push`/`import` 用
`-i/--input`。`pull` 的 `-o` 写成功清单 YAML，`export` 的 `-o` 是归档路径。

### `invalid hostname format, must be a domain name or localhost`

`registry install -H` 的主机名必须含 `.` 或就是 `localhost`（如 `harbor.example.com`）。

### `harbor version must start with 'v'`

`-v` 要带 `v` 前缀，如 `-v v2.5.0`。

### `target registry must start with http:// or https://`

`registry sync -t` 必须带协议头，源 `-s` 不带。

## 幂等与状态

`somcli install` 靠 `<workdir>/state.json` 判断资源是否已装。重跑会跳过已成功的步骤；
加 `--force` 强制重跑。若状态文件损坏或手动改过节点，可删掉对应资源的 state 记录再跑。
卸载用 `somcli uninstall -f config.yaml`，可加 `-n <资源名>` 只卸一个。

完整命令与标志见 [`11-命令参考.md`](11-命令参考.md)。

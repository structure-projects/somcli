# 场景：工具编排

> 覆盖验收场景：SC-M01、SC-M02、SC-M03、SC-E09。

用 somcli 装命令行工具——裸二进制、容器包装、系统包——一份配置统一管理。
完整示例是真实可运行的 [`configs/tools.yaml`](../configs/tools.yaml)：

```bash
somcli validate -f configs/tools.yaml     # 先校验
somcli install  -f configs/tools.yaml     # 全装
somcli install  -f configs/tools.yaml -n jq   # 只装 jq
somcli uninstall -f configs/tools.yaml    # 逆序卸载
```

## 三种 method

### `binary`：装裸二进制

kubectl 是典型例子：下载压缩包/裸二进制，装到 `install_dir`，置 0755。

```yaml
  # 节选自 configs/tools.yaml，只列 kubectl 这一个资源；vars 等外层字段见完整示例。
  - name: "kubectl"
    version: "1.28.0"
    method: "binary"
    install_dir: "{{.Vars.bin}}"
    urls:
      - "https://dl.k8s.io/release/v{{.Version}}/bin/{{.Platform}}/{{.Arch}}/kubectl"
    target: "{{.Filename}}"
    post_install:
      - "{{.Vars.bin}}/kubectl version --client"
    remove_scripts:
      - "rm -f {{.Vars.bin}}/kubectl"
```

下载物是归档（`.tar.gz`/`.zip`）会先解开，用 `files:` 指定归档内要装哪几个可执行文件，
留空则装归档里所有可执行文件。不想装到 `/usr/local/bin`（需要 root）就改 `install_dir`
到用户目录，或用 `--set bin=$HOME/bin` 覆盖 `vars`。

### `container`：镜像包一层包装脚本

helm 没发布单二进制，somcli 拉镜像，在 `install_dir` 生成一个同名包装脚本，
脚本自己找 docker/podman，之后直接敲 `helm` 即可：

```yaml
  - name: "helm"
    version: "3.12.0"
    method: "container"
    install_dir: "{{.Vars.bin}}"
    image: "alpine/helm:{{.Version}}"
```

### `package`：交给系统包管理器

jq 直接用目标机器上的包管理器装，包名缺省取 `name`。支持 apt/dnf/yum/zypper/apk/brew，
探测发生在目标节点上：

```yaml
  - name: "jq"
    method: "package"
    post_install:
      - "jq --version"
    remove_scripts:
      - "if command -v apt-get >/dev/null 2>&1; then apt-get remove -y jq; ..."
```

`method: package` 在目标上需要 root。加 `--sudo` 会在包管理器命令前加 `sudo`。
国内/离线环境配顶层 `source:` 在装包前换源，见 [`03-环境初始化.md`](03-环境初始化.md)。

## 常用操作

- **只装一个**：`somcli install -f configs/tools.yaml -n kubectl`
- **改安装目录**：`somcli --set bin=$HOME/bin install -f configs/tools.yaml`
- **看装了什么**：`somcli status`（读 `<workdir>/state.json`）
- **重装**：改资源 `version:`，或加 `--force` 无视幂等记录

## 远程装工具

工具编排同样支持远程：在 `nodes:` 声明机器，资源用 `hosts:` 点名，工具就装到对应节点。
完整远程示例见 [`configs/examples/remote-3node.yaml`](../configs/examples/remote-3node.yaml)。

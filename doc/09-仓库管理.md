# 场景：镜像仓库管理

> 覆盖验收场景：SC-C03、SC-C04。

`somcli registry` 管两件事：装一套 Harbor，以及在仓库之间批量同步镜像。

```bash
somcli registry install    # 装 Harbor
somcli registry uninstall  # 拆 Harbor
somcli registry sync       # 仓库间同步镜像
```

## 安装 Harbor

```bash
somcli registry install -H harbor.example.com -v v2.5.0
```

| 标志 | 默认 | 说明 |
|---|---|---|
| `-H, --hostname` | （必填） | Harbor 的访问主机名，必须是域名或 `localhost`（含 `.`） |
| `-v, --version` | `v2.5.0` | Harbor 版本，**必须带 `v` 前缀** |
| `--ca-path` | 空 | CA 证书目录；留空时 somcli 自签一对证书 |

前置条件：本机已装 `docker` 和 `docker-compose`（somcli 不替你装它们）。
安装过程：

1. 从 GitHub 下载 `harbor-offline-installer-<version>.tgz`（`--github-proxy` 生效），
   缓存到 `<workdir>/downloads/harbor/<version>/`。
2. 解压到 `<workdir>/apps/registry/harbor/`。
3. 由 `harbor.yml.tmpl` 渲染 `harbor.yml`：替换 hostname，数据目录指到
   `<installdir>/data`，日志指到 `<installdir>/logs`，证书路径指到 `--ca-path`
   （或自签证书所在目录）。
4. 执行目录里的 `install.sh`。

`install.sh` 是 Harbor 官方自带的，somcli 直接把 stdio 透传过去，它的输出就是 somcli 的输出。

## 卸载 Harbor

```bash
somcli registry uninstall
```

卸载只认安装目录：在 `<workdir>/apps/registry/` 下跑 `docker-compose down`，
然后删掉整个目录。`-v`/`-H` 可选，给了也只做格式校验，不参与卸载逻辑。

## 同步镜像 sync

```bash
somcli registry sync \
  -s docker.io \
  -t https://harbor.example.com \
  -f images.txt \
  -u admin -p Harbor12345 \
  -c 5
```

| 标志 | 默认 | 说明 |
|---|---|---|
| `-s, --source` | （必填） | 源仓库地址，用于名字替换，如 `docker.io` |
| `-t, --target` | （必填） | 目标仓库，**必须带 `http://` 或 `https://`** |
| `-f, --image-list` | （必填） | 镜像清单文件，每行一个 `name:tag`，`#` 注释 |
| `-u, --username` | 空 | 目标仓库登录用户 |
| `-p, --password` | 空 | 目标仓库密码；留空则读 `REGISTRY_PASSWORD` 环境变量 |
| `-c, --concurrency` | `3` | 并发数，1–10 |

同步对每张镜像做：`docker pull` → `docker tag` 成目标名 → `docker push` →
`docker rmi` 清掉本地和目标的临时镜像（清理失败不报错）。目标名的拼法：

- 镜像名里含 `--source` 字样：把 source 替换成目标主机。
- 镜像名不含 `/`（官方镜像，如 `nginx:latest`）：拼成 `<目标主机>/library/<镜像>`。
- 其余：拼成 `<目标主机>/<镜像>`。

`-u` 和 `-p` 都给了才会 `docker login` 目标仓库；都不给就跳过登录
（适合已经 `docker login` 过或匿名可推的场景）。密码优先用命令行，其次环境变量，
两者都没有直接报错退出。并发是起 goroutine 并发拉推，整体有任意一张失败就非 0 退出，
但不影响其他镜像继续跑完。

完整命令与标志见 [`11-命令参考.md`](11-命令参考.md)。

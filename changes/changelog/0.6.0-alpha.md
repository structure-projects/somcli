# Changelog

本文件记录 0.6.0-alpha 的变更。格式遵循 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/)。

## [0.6.0-alpha] - 2026-08-24

对应提案 `20260818-migrate-phase4-config-and-docs`（M4 配置归一与文档重建）。

这一版让"可测 = 可用 = 有文档"三者对齐：命令参考与功能矩阵改为从二进制命令树和
`test/matrix.yaml` 自动生成，CI 用 `git diff --exit-code` 守住，文档漂移从根上不可能
悄悄发生；`validate` 新增引用完整性校验，把"hosts 点了不存在的节点""k8sConfig.resources
写了清单里没有的名字"这类错误提前到连节点之前；14 份人工文档全量重建，每份场景文档的示例
配置都指向 `configs/examples/` 下被 CI 真实执行过的文件。

### BREAKING CHANGES

- **文档文件名整体调整，旧链接失效**。原先散落的 `doc/images.md`、`doc/registry.md`、
  `doc/offline.md` 改为按编号命名，并与其余场景文档统一进同一条阅读主线：

  | 旧文件 | 新文件 |
  |---|---|
  | `doc/images.md` | `doc/08-镜像管理.md` |
  | `doc/registry.md` | `doc/09-仓库管理.md` |
  | `doc/offline.md` | `doc/10-离线部署.md` |

  新增 `doc/00-功能清单与矩阵.md`（自动生成的命令清单 + 场景矩阵）与
  `doc/11-命令参考.md`（自动生成，取代手写命令说明）。`README.md` 重写为导航 + 5 分钟上手，
  页内有旧文档链接映射表。外部书签或引用旧路径的链接需要更新到新文件名。

- **`validate` 现在校验引用完整性**。此前 `hosts:` 写了未声明的节点、`k8sConfig.resources`
  或 `cni` 写了内置安装清单里没有的名字，要等到 `install`/`cluster create` 真的连节点、
  装到一半才报错；现在 `validate` 阶段就直接拦下并指出缺什么。只有 `localhost`/`127.0.0.1`
  /`::1` 可不经 `nodes:` 声明当作本机目标。判定与安装期 `utils.GetNode` 完全一致，不存在
  "validate 放过、install 翻车"的缝隙。

  迁移：对报 `hosts 项 "x" 不在已声明节点中` 的配置，把目标节点加进 `nodes:`（用其 `host`
  或 `ip` 字面量），或确认拼写；对报 `安装清单里没有资源 "x"` 的配置，照报错列出的可用名
  改正 `k8sConfig.resources`/`cni`。

- **`configs/kubernetes-cluster.yaml` 改为统一 schema 示例**。该文件早期版本是
  `kind: Download|Resource|App|Node|source` 多文档加 `flows`/`depends_on`/`Apps`/
  `roles`/`sources` 的设计草案——加载器只读第一个文档，其余键从未被任何代码消费（多文档
  在更早版本已被 `validate` 明确拒绝）。本版把它用真实存在的字段重写：节点在 `nodes:`
  声明，每个资源用 `hosts:` 点名落到哪些节点，产物走 `urls:`+`target:`，落盘文件走
  `extra_files:`。

  迁移：若你的配置是照旧草案抄的，`flows`/`depends_on`/`Apps`/`roles`（复数）/`sources`
  这些段在严格解析下本来就不生效，逐条改写指引见 `doc/roadmap.md` §5；按角色批量选节点
  尚未实现，暂时用每个资源的 `hosts:` 显式点名。

### Added

- **`hack/gendoc`**：由 `cobra/doc` 遍历命令树生成 `doc/11-命令参考.md`，每条命令的用法、
  标志、子命令与 `somcli <cmd> --help` 完全一致；关闭 cobra 的自动生成日期，保证重复生成
  零 diff。导出 `cmd.NewRootCommand()` 供工具在不触发 `Execute` 的前提下遍历。
- **`hack/genmatrix`**：由命令树 + `test/matrix.yaml` 渲染 `doc/00-功能清单与矩阵.md`。
  命令清单来自二进制，场景分组从 matrix.yaml 的 `# ---------- SC-X 标题 ----------`
  注释反射（不硬编码），done/pending 计数如实统计，未达成项不臆造为已验证。
- **CI `docs` job**（`.github/workflows/ci.yml`）：重新跑两个生成器并 `git diff --exit-code`
  守住 `doc/00`、`doc/11`；`Makefile` 增 `docs`/`gendoc`/`genmatrix` 目标。
- **`validate` 引用完整性校验**：`cmd/validate.go` 新增 `validateHostRefs`；
  `pkg/cluster` 导出 `ValidateConfigRefs` 复用集群安装期已有的清单名校验，不另写一套。
- **`configs/examples/remote-3node.yaml`**：真实可运行的三节点远程编排样例，由 multinode
  组 SC-E07 在容器 fixture 里原样执行（只替换 sshKey 路径），逐节点断言脚本落点。
- **场景文档防漂移用例**：
  - SC-X12（`test/local/doc_scenarios_test.go`）：`test/matrix.yaml` 里每个场景 ID 都必须在
    人工文档中出现，当前 93 个 ID 全部命中；生成物（00/11）与历史记录（提案-*、设计.md）
    排除，避免测试自我满足。
  - SC-X13：场景文档的 YAML 代码块不得出现顶层 `resources:`/`cluster:`/`images:`——
    可独立运行的配置一律落到 `configs/examples/` 按路径引用，讲解单字段的节选必须缩进。
- **14 份人工文档**（`doc/01`–`doc/13`、`doc/roadmap.md`）：概念与架构、资源编排字段全表、
  环境初始化（换源/离线/缓存布局）、工具与业务服务编排、Kubernetes/Swarm 集群、镜像与仓库
  管理、平台兼容矩阵（与 M3 实测逐格对应）、故障排查（按真实报错字符串归类）。

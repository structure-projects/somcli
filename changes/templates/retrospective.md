# B. 迭代复盘（版本发布 / 迭代结束）

## 数据收集（MUST 有数据支撑，MUST NOT 凭印象）

```bash
git log --since="<start>" --until="<end>" --oneline   # 周期内 commit
ls changes/archive/                                    # 周期内归档提案
```

PR / Issue 统计从 Git 平台获取；性能指标从监控系统获取。

## 概览

| 字段 | 值 |
|---|---|
| 周期 | YYYY-MM-DD ~ YYYY-MM-DD |
| 完成率 | 92%（12/13） |
| 团队 | <n> 人 |

## 做得好的（值得保留和推广）

- CI/CD 效率提升 30%（部署时间 20min → 14min）
- Code Review 质量提高，MUST fix 项减少 40%

- 测试覆盖率仍偏低（75%，目标 80%）

## 改进跟踪（每项 MUST 有负责人和截止日期）

## 约束

- **MUST NOT** 只说优点不说问题
